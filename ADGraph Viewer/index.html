Syntax and examples
MATCH (n:Computer) WHERE n.enabled = true RETURN n LIMIT 100
MATCH (u:User {dontreqpreauth: true}) RETURN u
MATCH p=(u:User)-[r:MemberOf*1..]->(g:Group {highvalue:true}) RETURN p
Properties can be inline or in WHERE. Named paths, chained patterns, shortestPath(...), *1.., bounded ranges such as *1..5, and relationship unions such as MemberOf|AdminTo are supported. Unbounded paths are safely capped at 12 hops. Neo4j projections such as DISTINCT, collect(...), aliases, and ORDER BY are accepted, but this viewer displays their matched subgraph rather than a result table.
